## 📖 Overview

This repository serves as a complete learning path for web development, featuring hands-on projects and examples across the full stack. From basic HTML/CSS layouts to advanced React applications and backend APIs, this collection provides practical examples and implementations for each technology.

## 🛠️ Technologies Covered

### Frontend
- **HTML5** - Semantic markup and structure
- **CSS3** - Styling, layouts, and responsive design
- **JavaScript (ES6+)** - Programming fundamentals, DOM manipulation, async/await
- **React** - Component-based UI development, hooks, state management
- **Redux** - State management for complex applications

### Backend
- **Node.js** - Server-side JavaScript runtime
- **Express.js** - Web application framework
- **MongoDB** - NoSQL database
- **Mongoose** - MongoDB object modeling

### Tools & Others
- **Git** - Version control
- **npm/yarn** - Package management
- **REST APIs** - API design and implementation

## 🚀 Getting Started

### Prerequisites

Before running any projects, ensure you have the following installed:

- **Node.js** (v14 or higher) - [Download here](https://nodejs.org/)
- **MongoDB** (for backend projects) - [Download here](https://www.mongodb.com/)
- **Git** - [Download here](https://git-scm.com/)
- **Code Editor** (VS Code recommended) - [Download here](https://code.visualstudio.com/)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/kushagraSrivastava9651/FullStackWebDevlopment.git
   cd FullStackWebDevlopment
   ```

2. **Install root dependencies** (if any)
   ```bash
   npm install
   ```

## 💻 Usage

### HTML/CSS Projects
Navigate to any `html_css/lecture*/` directory and open the `.html` files in your browser to view the examples.

### JavaScript Projects
1. Navigate to any `javascript/javascript*/` directory
2. Open the `index.html` file in your browser or
3. Run with a local server for better experience

### React Projects
1. Navigate to any `React/React-*/` directory
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```

### Backend Projects
1. Navigate to any `Backend/*/` directory
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up environment variables (create `.env` file)
4. Start the server:
   ```bash
   npm run dev
   ```
